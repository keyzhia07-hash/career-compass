# Career Compass

voici mon site internet actuel https://test.curtispc.fr/ L'idée est que l'éditeur de cv et lettre de motivation reste sur le même thème.  En pièce jointe, tu trouveras une capture d'écran de mon éditeur de CV actuel, ma page ATS, ma page tableau de bord, Ma page recherche d'emploi (Sur mon site actuel, j'aime bien la rubrique : Offres d'emploi Vos offres, cherchées pour vous.) Mais j'aimerais rajouter une carte qui permet de visualiser l'endroit où se trouve le travail Pour la page recherche d'emploi. Il suffit pas de les cloner, mais c'est juste une idée de ce que j'ai déjà.
